## الملفات
| الملف | الدور |
|---|---|
| `config.js` | **الملف الوحيد الذي يتغير بين المساجد/المدارس** |
| `index.html` | الواجهة والتصميم (الكتاب الافتتاحي، رجال الفجر، البطاقات…) |
| `js/a1.js` … `js/a5.js`، `js/posts.js`، `js/demo.js` | منطق المنصة (تُحمَّل بالترتيب: أدوات وتخزين ومزامنة / المسح والحضور والمدونة / الواجهات / الأحداث والتشغيل) |

## الأقسام
- **عام:** الرئيسية (أوقات الصلاة، رجال الفجر، منشور الاثنين/الجمعة)، احجز مقعدًا، المدونة، **بوابة الأولياء**، رأيكم يهمنا، جولة تجريبية (`?demo=1`).
- **الطاقم:** الطلاب، طلبات التسجيل، الحضور والغياب (اليوم أو أي يوم سابق، غائب/غائب بعذر)، رجال الفجر، التسميع، الأفواج والتوقيت، البطاقات (مع تصوير الفوج بالتتابع)، الحقوق والوصولات، المدونة، المساعد، الإعدادات.
- **بوابة الأولياء:** رقم التسجيل + رمز الولي (يُولَّد عند التسجيل ويُرسل عبر واتساب). تعمل عبر الإنترنت بعد ربط جدول Google (إجراء `parent` في Code.gs يعيد سجلّ طالب واحد فقط).
- **منشورات الاثنين والجمعة:** `js/posts.js` قائمة نصوص مراجَعة منسوبة؛ تُنشر بالترتيب ابتداءً من `postsStart` في config.js (اختياري).
- **Web Analytics:** فعّلها من لوحة Vercel ← Analytics ← Enable.

## نسخ القالب لمسجد أو مدرسة أخرى
1. انسخ كل الملفات.
2. عدّل `config.js` فقط:
```js
window.QS_CONFIG = {
  name: 'اسم المسجد أو المدرسة',
  the: 'المسجد',            // أو 'المدرسة' — تظهر في الجمل: «إدارة المسجد»
  place: 'البلدية · ولاية …',
  prefix: 'HN',             // بادئة أرقام الطلاب HN-0001
  wilaya: 28,               // رقم الولاية
  commune: { name: 'المعاضيد', lat: 35.771089, lng: 4.750766 }, // تُضبط أيضًا من الإعدادات
  gs: ''                    // رابط Web app بعد ربط جدول Google (لتفعيل نموذج الحجز العام)
};
```
3. بدّل `logo.webp` و`bg.avif` إن أراد المسجد صوره الخاصة.
4. انشر على Vercel باسم مشروع جديد.

## تشغيل المسجد (خطوات المسؤول)
1. افتح الرابط → «دخول الطاقم» → أنشئ حساب المدير (رمز 6 أرقام).
2. الإعدادات → «اربط بجدول Google»: حساب Gmail **للمسجد** → جدول جديد → Extensions › Apps Script → ألصق Code.gs وضع كلمة السر المولَّدة → Deploy › Web app (Execute as: Me، Anyone) → ألصق الرابط.
3. ضع نفس رابط Web app في `config.js` (الخانة gs) وأعد النشر ليعمل نموذج الحجز للأولياء.
4. أنشئ المعلمين والأفواج، ثم الطلاب، ثم اطبع البطاقات.
5. الأجهزة الأخرى: «ربط هذا الجهاز» بالرمز MQ1-… من الإعدادات.

## قواعد ثابتة
- المنصة وقف لله بالكامل؛ لا شكر إلا الدعاء بظهر الغيب. توقيع صغير فقط: «تطوير donialabstech».
- المساعد لا يُفتي ولا يفسّر ولا يكتب نصًّا قرآنيًا؛ يجيب من أرقام المسجد فقط.
- نصوص المدونة ثابتة ومراجعة يدويًا مع العزو.
- بيانات كل مسجد في جدوله هو. لا تُطلب كلمات سر Gmail أبدًا.
- رجال الفجر: 40 يومًا متتالية = كأس؛ 10 نقاط لليوم و100 للكأس (قابلة للتعديل)؛ المسح من 15 دقيقة قبل الأذان إلى الشروق.
